Auto Bug Report Generator Integration Guide

How to automatically intercept crashes in any Python pipeline with decorators, context managers, and global exception hooks.

Method 1: Decorator

@auto_report

Wrap any mission-critical function. Catches uncaught exceptions, writes a detailed report, and optionally suppresses or reraises.

from bug_reporter import auto_report

@auto_report(reports_dir="reports", reraise=False)
def calculate_metrics(values):
    return sum(values) / len(values)
Method 2: Context Manager

with MonitorErrors()

Safely scope a fragile block of code (e.g. network requests, file I/O, parsing) without decorating the whole function.

from bug_reporter import MonitorErrors

with MonitorErrors(reports_dir="reports", reraise=False) as monitor:
    with open("config.json") as f:
        data = f.read()

if monitor.report_path:
    print(f"Handled! Report: {monitor.report_path}")
Method 3: Global Exception Hook

install_global_hook()

Set a safety net over your entire application. Any uncaught crash generates a report right before termination.

from bug_reporter import install_global_hook

# At the very top of your entrypoint
install_global_hook(reports_dir="reports")

# Application code runs normally...
